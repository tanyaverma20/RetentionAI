# Lite dependency set — prediction, SHAP explainability and the decision
# engine, without the local inference stack.
#
# Measured RSS after importing this set: ~265 MB, versus ~496 MB for the full
# requirements.txt (before any model weights load). That difference is what
# makes the service fit a 512 MB free-tier container.
#
# Omitted, and why each is safe to omit here:
#   torch, transformers        — only the NLP emotion/zero-shot classifiers
#   sentence-transformers      — only RAG embeddings
#   chromadb                   — only the RAG vector store
#   spacy, nltk, vaderSentiment, langdetect — NLP preprocessing only
#   pypdf, docx2txt, unstructured, markdown — document ingestion for RAG only
#
# app/features.py detects their absence and swaps the NLP/RAG routes for a 503
# stub, so a lite deployment reports what it cannot do instead of failing at
# import time. Keep the shared pins below in lockstep with requirements.txt —
# a version skew between the two images would be invisible until runtime.
